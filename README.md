# AutoFormat Report Generator

Скрипт для автоматического форматирования отчетов в формате '.docx'.

## Как это работает
Программа принимает текстовый файл и автоматически применяет стили по ключевым слова:
- **Шапка документа** -> выравнивание по центру (Times New Roman, 14, интервал 1.5).
- **Задача / Решение / Выводы** -> выравнивание по ширине (Times New Roman, 14, интервал 1.5).
- **Исходный код** -> выравнивание по левому краю (Courier New, 12, интервал 1.0).
