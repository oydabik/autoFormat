# autoFormat

Автоматическое форматирование студенческих отчётов `.docx` → `.docx`.

Программа читает отчёт, распознаёт блоки (шапка, задачи, подзаголовки,
код, картинки, списки) и применяет к ним фиксированные стили.

---

## Структура отчёта

Одна «задача» в отчёте выглядит так:

```
[SECTION]    Задача N. текст задачи
[SUBHEADER]  Решение.
[SUBHEADER]  Скриншоты
[IMAGE]      картинка 1
[IMAGE]      картинка 2
             ↓ пустая строка (генерируется)
[SUBHEADER]  Исходный код
[CODE]       код
             ↓ пустая строка (генерируется)
[SECTION]    Выводы
[LIST_ITEM]  1. ...
[LIST_ITEM]  2. ...
[LIST_ITEM]  3. ...
             ↓ пустая строка (генерируется)
[SECTION]    Задача N+1. текст следующей задачи
```

Отчёт начинается с шапки (`TITLE`), затем идёт одна или несколько
таких задач подряд.

---

## Стили абзацев

| Стиль        | Применяется к                                | Выравн. | Шрифт       | Разм. | Интерв. | До/после | Left     | First line |
|--------------|----------------------------------------------|---------|-------------|-------|---------|----------|----------|------------|
| `TITLE`      | шапка (несколько строк)                      | center  | TNR         | 14    | 1.5     | 0        | 0        | 0          |
| `SECTION`    | `Задача N.`, `Выводы`                        | justify | TNR         | 14    | 1.5     | 0        | 0        | 0          |
| `SUBHEADER`  | `Решение.`, `Скриншоты`, `Исходный код`      | justify | TNR         | 14    | 1.5     | 0        | 0        | 0          |
| `BODY`       | обычный текст                                | justify | TNR         | 14    | 1.5     | 0        | 0        | 0          |
| `CODE`       | код                                          | left    | Courier New | 12    | 1.0     | 0        | 0        | 0          |
| `LIST_ITEM`  | пункты выводов                               | justify | TNR         | 14    | 1.5     | 0        | 1.25 см  | −1.25 см   |

`TNR` = Times New Roman.
`Left` и `First line` — отступы в сантиметрах.
`LIST_ITEM` использует висячий отступ: номер стоит на левом краю,
переносы строк — с отступом.

---

## Типы блоков и как их определять

| Тип          | Признак                                                              |
|--------------|----------------------------------------------------------------------|
| `TITLE`      | все абзацы до первой `Задача`                                        |
| `SECTION`    | `startswith` `Задача` / `Выводы`                                     |
| `SUBHEADER`  | `startswith` `Решение.` / `Скриншоты` / `Исходный код`               |
| `LIST_ITEM`  | regex `^\d+\.\s`                                                     |
| `CODE`       | все абзацы между `Исходный код` и следующим `SECTION` / `SUBHEADER`  |
| `IMAGE`      | абзац содержит `w:drawing`                                           |
| `BODY`       | всё остальное                                                        |

---

## Правила пустых строк

Пустые абзацы **генерируются по правилам**, а не копируются из исходника.
Пустые абзацы входного документа игнорируются полностью.

| После чего                          | Пустая строка |
|-------------------------------------|---------------|
| Шапка (последний блок)              | НЕТ           |
| `Задача N.` (SECTION)               | НЕТ           |
| `Решение.` (SUBHEADER)              | НЕТ           |
| `Скриншоты` (SUBHEADER)             | НЕТ           |
| Последняя картинка в группе         | **ДА**        |
| Код                                 | **ДА**        |
| Список выводов (последний пункт)    | **ДА**        |
| Всё остальное                       | НЕТ           |
